# *Расчётно-графическая работа*
## Вариант №10 *Список анаграмм*

### Задание
Разработать программу Anagram, выводящую список всех анаграмм
для заданного слова. Программа принимает в качестве аргумента командной строки имя файла, содержащего слово на русском или английском языке.
Анаграммами называются все возможные перестановки букв (независимо от
того, являются ли они допустимыми словами). Количество вариантов равно
факториалу количества букв.

---
### Принцип работы
Напишем функцию, которая буде вызывать сама себя и генерировать слова
следующим путём:
• Возьмем первый символ слова и поместим его в префикс (переменную,
хранящую слово в процессе генерации)

• Оставшееся слово поместим в другую переменную и подадим на следую-
щий рекурсивный вызов функции

• Проверим, остались ли во второй переменной еще символы, если да, то
вызываем функцию еще раз, иначе записываем получившуюся анаграмму в
массив с результатами

• Повторяем до тех пор, пока не пройдем циклом все буквы слова

### Компиляция и запуск

```bash
mkdir build && cd build

cmake ..

make
```

В папке build создайте текстовый файл (например, input.txt) и запишите туда слово. Запустите командой:

```bash
./anagram_generator input.txt
```
